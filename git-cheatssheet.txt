
ШПАРГАЛКА ПО ОСНОВНЫМ КОМАНДАМ GIT
Выполнил: ЧУМАЧЕНКО МИХАИЛ ИСП-242


1. НАСТРОЙКА И ИНИЦИАЛИЗАЦИЯ:
   - git config --global user.name "Ник"  -> Задать имя автора коммитов.
   - git config --global user.email "mail" -> Задать почту автора коммитов.
   - git init -b main                     -> Создать новый локальный репозиторий с веткой main.

2. РАБОТА С ИЗМЕНЕНИЯМИ (ИНДЕКС И КОММИТЫ):
   - git status         -> Проверить текущее состояние файлов (Untracked, Modified, Staged).
   - git add .          -> Добавить абсолютно все измененные и новые файлы в индекс.
   - git add <путь>     -> Подготовить конкретный файл к коммиту.
   - git commit -m "сообщение" -> Создать коммит (сохранить версию) с описанием.

3. ПРОСМОТР ИСТОРИИ:
   - git log            -> Показать подробную историю коммитов (SHA, Автор, Дата).
   - git log --oneline  -> Показать историю в компактном виде (одна строка на коммит).
   - git show <хеш>     -> Показать изменения (Diff) внутри конкретного коммита.

4. УПРАВЛЕНИЕ ВЕТКАМИ (BRANCHES):
   - git branch         -> Список локальных веток (* указывает на текущую).
   - git branch -a      -> Список всех локальных и удаленных (remote) веток.
   - git switch -c фича -> Создать новую ветку и сразу переключиться на нее.
   - git switch имя_ветки -> Просто переключиться на существующую ветку.
   - git branch -d фича -> Безопасное удаление ветки (после слияния).

5. УДАЛЕННЫЕ РЕПОЗИТОРИИ (GITHUB / GITFLIC):
   - git remote add origin <ссылка>  -> Связать локальный проект с удаленным репозиторием.
   - git remote -v                   -> Проверить адреса привязанного удаленного репозитория.
   - git push -u origin main         -> Первая отправка ветки main на сервер с отслеживанием.
   - git push                        -> Обычная отправка коммитов на сервер (после настройки -u).
   - git pull                        -> Стянуть и объединить изменения с сервера в локальный код.
   - git fetch --prune               -> Синхронизировать список веток, удалив несуществующие.
